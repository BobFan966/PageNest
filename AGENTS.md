## Design System

Always read DESIGN.md before making any visual or UI decisions.
All font choices, colors, spacing, and aesthetic direction are defined there.
Do not deviate without explicit user approval.
In QA mode, flag any code that doesn't match DESIGN.md.

The approved visual system does not resolve pending interaction decisions in docs/review-v0.1.md. Keep prototype behavior, approved product requirements, and verified application behavior distinct.

Current approved direction (2026-10-30): PageNest VI + macOS Vibrancy, with a silver-white page-into-nest mark, Source Sans 3 wordmark, layered dark grays, and blue interaction highlights. Use DESIGN.md as the source of truth; earlier light/teal concepts in output/brand/ and archived previews are historical references. Visual approval does not imply production implementation or acceptance.
